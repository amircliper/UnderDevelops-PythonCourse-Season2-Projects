## 📚 درباره این Repository

این مخزن، کدهای فصل پروژه‌های عملی دوره Python را در یک مسیر آموزشی مشخص نگهداری می‌کند.

در هر پروژه، برنامه از یک نسخه ساده شروع می‌شود و در چند مرحله توسعه پیدا می‌کند. بنابراین فقط با نسخه نهایی روبه‌رو نیستید؛ می‌توانید ببینید یک پروژه پایتون چگونه مرحله‌به‌مرحله طراحی، اصلاح، توسعه و در نهایت ماژول‌بندی می‌شود.

این شیوه برای کسانی مناسب است که می‌خواهند **آموزش پایتون پروژه‌محور** را دنبال کنند و بعد از یادگیری سینتکس Python، مهارت‌هایی مثل حل مسئله، طراحی منطق برنامه، اعتبارسنجی ورودی، مدیریت خطا، کار با داده و ساختاردهی پروژه را تمرین کنند.

> 💡 پیشنهاد می‌کنیم مراحل هر پروژه را به ترتیب جلو بروید و قبل از مشاهده کد مرحله بعد، خودتان قابلیت جدید آن مرحله را پیاده‌سازی کنید.

## 🗂️ ساختار پوشه‌ها چگونه است؟

ساختار کلی مخزن به این شکل است:

```text
Python-Projects/
│
├── پروژه ۰۱ - ماشین حساب هوشمند/
├── پروژه ۰۲ - مسابقه اطلاعات عمومی/
├── پروژه ۰۳ - مدیریت دانشجو و نمرات/
```

```text
پروژه ۰۱ - ماشین حساب هوشمند/
│
├── ۰۱ - ساخت نسخه اولیه ماشین حساب/

├── ۰۲ - تبدیل عملیات ها به تابع/
│   └── main.py
│
├── ۰۳ - ساخت منوی تعاملی و اجرای پیوسته/
│   └── main.py
│
├── ...
│
└── ۰۹ - ماژول بندی و تکمیل پروژه/
    ├── main.py

    ├── validators.py
    ├── decorators.py

```

### هر مرحله چه معنایی دارد؟

هر فولدر شماره‌دار، وضعیت پروژه در همان مرحله از آموزش است.

برای مثال، کد موجود در مرحله `۰۳` ادامه مستقیم مرحله `۰۲` است و قابلیت‌های جدیدی به آن اضافه شده است. به همین دلیل بهتر است پوشه‌ها را به ترتیب شماره بررسی کنید.

پوشه آخر هر پروژه معمولاً **نسخه کامل‌تر و ماژول‌بندی‌شده پروژه** را شامل می‌شود؛ اما هدف اصلی این Repository فقط ارائه کد نهایی نیست، بلکه نمایش مسیر رسیدن به آن نسخه است.

## 📄 فایل‌های داخل پروژه‌ها

بسته به مرحله‌ای که در آن قرار دارید، ممکن است فایل‌های مختلفی ببینید.

### `main.py`

نقطه شروع اجرای برنامه است. در مراحل ابتدایی معمولاً بخش زیادی از منطق پروژه در همین فایل قرار دارد.

### فایل‌های ماژول Python

در مراحل نهایی، مسئولیت‌های مختلف از `main.py` جدا می‌شوند و در فایل‌های مستقل قرار می‌گیرند. برای مثال:

```text
validators.py
reports.py
data_store.py
decorators.py
services.py
json_tools.py
permissions.py
```

نام فایل‌ها در پروژه‌های مختلف متفاوت است، اما ایده اصلی یکسان است: **هر بخش از برنامه مسئولیت مشخص خودش را داشته باشد.**

### `requirements.txt`

در بعضی از پروژه‌های نهایی این فایل وجود دارد. اگر پروژه به پکیج خارجی نیاز داشته باشد، وابستگی‌های آن از طریق این فایل نصب می‌شوند.

## ▶️ چطور از پروژه‌ها استفاده کنیم؟

### ۱. دریافت Repository

Repository را با Git کلون کنید یا از طریق گزینه **Download ZIP** در GitHub دریافت کنید.

اگر Git را نصب دارید:

```bash
git clone <repository-url>
```

### ۲. یک پروژه را انتخاب کنید

مثلاً وارد پوشه زیر شوید:

```text
پروژه ۰۱ - ماشین حساب هوشمند
```

### ۳. مرحله موردنظر را باز کنید

اگر تازه پروژه را شروع کرده‌اید، از مرحله `۰۱` شروع کنید و به ترتیب جلو بروید.

```text
۰۱ → ۰۲ → ۰۳ → ... → مرحله نهایی
```

### ۴. برنامه را اجرا کنید

داخل فولدر همان مرحله، فایل اصلی را اجرا کنید:

```bash
python main.py
```

در بعضی سیستم‌ها ممکن است دستور زیر استفاده شود:

```bash
python3 main.py
```

## 🧪 برای یادگیری بهتر، فقط کد را اجرا نکنید

بهترین روش استفاده از این Repository این است که آن را به‌عنوان **تمرین برنامه‌نویسی پایتون** ببینید، نه صرفاً مجموعه‌ای از جواب‌ها.

پیشنهاد مسیر کار:

1. عنوان مرحله بعد را بخوانید.
2. قبل از باز کردن کد آن مرحله، خودتان قابلیت موردنظر را پیاده‌سازی کنید.
3. کد خودتان را اجرا و تست کنید.
4. سپس راه‌حل موجود در Repository را بررسی کنید.
5. تفاوت دو پیاده‌سازی را تحلیل کنید.
6. در پایان، نسخه خودتان را بهبود دهید.

این کار باعث می‌شود به‌جای حفظ کردن کد، **تفکر برنامه‌نویسی و حل مسئله** را یاد بگیرید.
